# Evidencias

Capturas de las pruebas del sistema de almacenamiento distribuido con gRPC.
`Registro_de_evidencias.pdf` describe cada una: qué se hizo y qué se observa.

| ID | Prueba |
| --- | --- |
| E01–E08 | Terminal: registro, chequeo de salud, ping, subida con réplicas, NOT_FOUND, caída y recuperación |
| E09–E13 | Panel web y API (200 y 404) |
| E14–E15 | Confirmación de subida y eliminación de archivos |
| E16–E18 | Despliegue con Tailscale: acceso remoto, red lenta y nodo en un segundo computador |
| E19–E22 | Tolerancia a fallos: re-replicación, resincronización e indicador de riesgo |
| E23 | Cuentas y permisos: acceso móvil de un usuario sin permiso para eliminar |
